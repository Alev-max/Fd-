组件占位符用法说明

什么是组件？

组件是定义在 Storyline 中的自定义 HTML 小部件。当 AI 在回复中输出对应的占位符标签时，消息气泡会将其渲染为可交互的 HTML 界面。

AI 如何调用组件？

AI 输出以下格式的标签，其中 name 为你定义的组件名：

<$组件名$>
  <变量A>值A</变量A>
  <变量B>值B</变量B>
</$组件名$>
组件内部的 <变量>值</变量> 会作为参数传入，在“组件源码”里的 <script> 中通过 $变量A$ 等占位符引用。

组件源码怎么写？（单栏位）

现在只需填写一个“组件源码”输入框，不再分成 HTML / CSS / Script 三个栏位。推荐在同一个输入框里按「HTML + style + script」顺序编写：

<div class="box">
  <div data-result>等待输入...</div>
</div>

<style>
.box { border: 1px solid #6366f1; padding: 10px; border-radius: 10px; }
</style>

<script>
setText('[data-result]', '$文本$')
show('[data-result]')
</script>
系统会自动从这个单栏位源码中拆分并处理 HTML / CSS / Script。你也可以直接粘贴完整 HTML 文件；源码中的 $变量名$ 会替换为 AI 传入的参数值。

脚本执行规则

组件源码中的 <script> 支持白名单内置函数，无需写完整 JS。若检测到原生 JS 代码，系统会自动切换到隔离的 iframe（禁止网络请求）执行，保障安全。

常用白名单函数示例：

requireInputEquals('[data-field]', '$值$', '错误提示')
progress('[data-bar]', '[data-text]', 1500)
setText('[data-result]', '$文本$')
setText('[data-world-info]', getWorldInfo('吸血鬼'))
setValue('[data-avatar]', getCharAvatar())
show('[data-result]')
hide('[data-result]')
像 getMsgContent()、getUserAvatar()、getCharAvatar()、readFromLocal()、getWorldInfo() 这类 getter 可以直接作为其他函数的参数。

输入框与触发按钮

若组件内有输入框，建议给提交/触发按钮添加 data-component-trigger="1" 属性，避免用户在输入框中按 Enter 时误触发全局发送。

<button data-component-trigger="1">提交</button>
AI 提示词（ai_prompt）

在 "AI提示" 栏填写示例调用格式，系统会自动将其注入到 System Prompt 末尾，引导 AI 在合适时机输出该组件。

组件源码（支持完整单文件 HTML，或仅写 <div>+<style>+<script> 片段）
支持完整 HTML 文档和无 <html> 包裹的片段；检测到原生 JS 时会在隔离 iframe 中运行（禁网络）。参数占位符：$账号$、$密码$、$文本$。
